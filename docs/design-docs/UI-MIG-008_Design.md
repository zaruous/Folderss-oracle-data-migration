# UI-MIG-008. 마이그레이션 설정 (팝업 + Folderss 설정 탭)

## 1. 화면 내용 요약

- **목적**: Migration Studio 플러그인 자체의 설정을 고친다 — 이관에 쓸 **접속 목록**, 새 작업의 **기본값**(전략·체크포인트 저장소), 하위 프로세스 **실행 에이전트** 동작. 접속은 이 플러그인 설정에만 두고 DB Helper와 공유하지 않는다.
- **여는 곳**: 플러그인 안 `파일 > 마이그레이션 설정…` · 아이콘 막대 ⚙ · 접속 화면 [마이그레이션 설정…]·[접속 관리…] / Folderss `설정 > 플러그인 > Migration Studio` 탭(IPluginSettingsPage). 두 곳은 같은 View를 쓴다.
- **주요 기능**:
  - 접속 탭: 목록(추가·복제·삭제, 작업에서 쓰는 중이면 "원본·대상" 표시) + 편집(접속 이름·색 표시·DB 종류·기본 스키마·호스트·포트·서비스명·사용자·비밀번호(저장)·**쓰기 금지(원본 전용)**) + 접속 테스트
  - 기본값 탭: 커밋 단위·Fetch 크기·병렬 작업자·오류 처리·오류 테이블 접두어, **체크포인트 저장소**(자동·대상 DB 제어 테이블·로컬 파일), 제어 테이블 접두어
  - 실행 에이전트 탭: Folderss를 닫을 때(계속 실행·함께 중지), 동시에 실행할 작업 수, 실행 로그 보관 기간, 실행 파일·통신 방식·실행 중인 에이전트 표시
  - 고친 내용은 사본에 모았다가 [저장]할 때 한 번에 반영(검사 실패면 해당 접속으로 이동)

## 5. 기타 특이사항

- **유효성 검사**: [저장]할 때 모든 접속을 검사한다(FUNC02). 접속 이름은 작업 파일이 다른 PC에서 접속을 찾는 열쇠이므로 겹칠 수 없다.
- **권한 처리**: 설정은 이 Windows 사용자의 플러그인 데이터 폴더에만 저장한다. 비밀번호는 DPAPI(CurrentUser)라 다른 PC·다른 사용자는 풀 수 없다(다시 입력).
- **팝업**: 이 화면 자체가 팝업(위에 제목, 아래 오른쪽 [취소]·[저장], Esc = 취소). Folderss 설정 창의 플러그인 탭에서는 같은 View를 넣고 설정 창의 [저장]이 FUNC01을 부른다(`IPluginSettingsPage.Save`).
- **기타**:
  - **DB Helper와 공유하지 않는다**: DB Helper의 `connections`(엔트로피 `Folderss.OracleHelper.v1`)는 읽지 않는다. Migration Studio는 자기 키 `migration-settings`와 자기 엔트로피(예: `Folderss.Migration.v1`)를 쓴다.
  - 작업 파일에는 접속 참조(`profileId`)와 이름·주소 사본만 들어간다(UI-MIG-001·007). 접속 이름을 바꾸면 그 접속을 쓰는 작업은 `profileId`로 계속 이어진다.
  - `plugin.json`의 `"hasSettings": true` — 플러그인을 실행하기 전에도 Folderss 설정 창에 탭 자리가 보인다(Folderss 플러그인 규칙).
